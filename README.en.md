# DocTrainAI 文档培训职能平台

#### Description
面向企业内部规章与员工培训场景，基于Vue3+FastAPI+LangGraph构建。内置RBAC权限底座，支持部门、用户、课程、文档管理；接入通义千问实现权限感知RAG智能 Agent，具备多轮流式对话、原文溯源、意图判断能力。架构插件化解耦，增量叠加多路召回、重排、幻觉校验等优化。Docker+Gitee Actions完成CI/CD自动化部署，是一套可迭代、贴近企业规范的 AI 全栈应用项目
