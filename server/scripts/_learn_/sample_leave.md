# 员工年假管理制度

## 一、适用范围
本制度适用于公司全体员工（含试用期转正员工）。

## 二、年假标准
员工连续工作满1年不满10年的，年休假5天；满10年不满20年的，年休假10天；满20年及以上的，年休假15天。年假按自然年度计算，当年未休完的，可结转至次年第一季度内休完，逾期自动作废。

## 三、申请流程
员工休年假应提前3个工作日填写《请假申请单》，注明休假起止时间，经直属上级审批后执行。年假可分多次休，单次不少于半天。

## 四、其他规定
年假优先于事假使用；病假、产假等法定假期不影响年假计算。员工离职时，当年应休未休的年假按公司规定折算补偿或安排补休。

本制度自发布之日起施行，由行政人事部负责解释。
